# 003MOTO — başlanğıc versiyası

Bu layihə 003MOTO motosiklet elan platformasının ilk işlək frontend versiyasıdır.

## İşə salmaq

1. Bu qovluğu VS Code ilə aç.
2. VS Code-da `Terminal -> New Terminal` seç.
3. Yaz:

```bash
npm install
```

4. Sonra:

```bash
npm run dev
```

5. Brauzerdə aç:

http://localhost:3000
